# WavePet

작업할 때 켜 두는 데스크탑 위젯입니다. 유튜브 등에서 음악을 틀면 왼쪽 파형이 소리에 맞춰
움직이고, 오른쪽 캐릭터가 음악을 같이 듣는 것처럼 반응합니다. Electron 기반이며,
**시스템 오디오 루프백 캡처**로 스피커로 나가는 소리를 그대로 분석하므로 브라우저,
스포티파이 등 어떤 앱에서 재생하든 동작합니다(Windows 기준).

> 현재 **3단계(캐릭터 반응)** 상태입니다.

## 캐릭터 반응

- 캐릭터 그림은 세 장입니다: **노래 안 들을 때(idle)**, 노래 들을 때 번갈아 보여 주는 **왼쪽(left)·오른쪽(right)**.
- 노래가 재생되면 **바로** 듣는 중(listening)이 되어 **고개를 까딱까딱**하고, 멈추면 **바로** 가만히 있는
  상태(idle)로 돌아갑니다. 재생 앱이 Windows에 알려 주는 재생 상태를 따르므로 곡 중간의 조용한 부분에도
  바뀌지 않습니다.
- 재생 상태를 알려 주지 않는 앱이면 소리 크기로 판단합니다(0.5초 이상 소리 나면 듣는 중, 2초 이상 조용하면 idle).
- 고개 까딱: 일정한 리듬으로 left/right 그림을 번갈아 보여 주고, 그때마다 몸을 좌우로 기울이고 살짝
  올라갔다 내려옵니다. left/right 그림을 못 쓰면 idle 그림을 그대로 보여 줍니다.
- **애니메이션 설정**(설정 창 → 애니메이션, 바로 반영·저장):

  | 항목 | 범위 | 기본값 |
  |---|---|---|
  | 까딱 간격 | 0.4~2.0초 | 0.9초 |
  | 좌우 기울기 | 0~10도 (0이면 안 기울어짐) | 0도 |
  | 통통 높이 | 0~8% (0이면 안 튐) | 2.5% |
  | 박자에 맞춰 ♪ 음표 | 켜기/끄기 | 켜기 |
- **캐릭터 크기**: 설정 창의 슬라이더로 60~120% 사이에서 조절할 수 있고, 다음 실행에도 유지됩니다.
- 저음(킥 드럼) 박자를 세어 4박자에 한 번 머리 위로 ♪가 떠오릅니다(설정에서 끌 수 있음).
- 캐릭터 그림은 우클릭 또는 ••• 메뉴 → **설정 (배경 · 캐릭터)...**에서 **노래 안 들을 때 / 들을 때 · 왼쪽 /
  들을 때 · 오른쪽** 각각 내 PC의 이미지로 바꿀 수 있습니다(PNG·GIF·WebP·JPG). 고른 그림은 앱 데이터 폴더에 복사되어
  원본을 옮겨도 유지되고, **기본** 버튼으로 되돌릴 수 있습니다. 트레이 아이콘은 '노래 안 들을 때' 그림을 따라갑니다.
- 캐릭터는 캔버스에 직접 그립니다. 원본을 화면에 실제로 찍히는 픽셀 크기(와 그 2배)로 미리 고품질 축소해
  두고, 기울기 0일 때는 화면 픽셀에 1:1로, 기울어 있을 때는 2배 그림에서 고품질로 회전해 그려서 까딱이는
  동안에도 선이 흐려지지 않습니다. 통통 높이도 화면 픽셀 단위로 맞춥니다.
- 그림마다 여백이 달라도 괜찮습니다. 투명하지 않은(실제로 그려진) 영역을 자동으로 재서, 모든 표정을 같은
  기준으로 캐릭터 칸(크기 100%일 때 104px 폭)에 딱 맞게 배치합니다(PNG·JPG 기준, GIF·WebP는 그림 전체로 맞춤).
  표정끼리는 캔버스 크기와 캐릭터 위치를 똑같이 맞춰 그려야 바뀔 때 튀지 않습니다.
- 기본 그림(`assets/pet/`, 512×512 투명 PNG, 세 그림의 캐릭터 위치를 똑같이):

  | 파일 | 언제 |
  |---|---|
  | `idle.png` | 노래 안 들을 때 (눈 뜬 모습) |
  | `left.png` | 노래 들을 때 · 왼쪽으로 까딱 (눈 감고 왼쪽으로 기운 모습) |
  | `right.png` | 노래 들을 때 · 오른쪽으로 까딱 (눈 감고 오른쪽으로 기운 모습) |

## 음악 플레이어 카드

유리 느낌의 카드(100%일 때 360×176) 안에 곡 정보, 파형, 캐릭터, 진행 바, 재생 버튼이 들어 있습니다.

- **위젯 크기**: 설정 창 맨 위 슬라이더로 70~160% 사이에서 카드 전체(글자·파형·캐릭터·버튼)를 같은
  비율로 키우거나 줄일 수 있습니다. 창의 오른쪽 아래 모서리를 고정한 채 크기가 바뀌고, 다음 실행에도 유지됩니다.
  그림을 늘리는 게 아니라 페이지 확대(zoom factor)로 그 배율에 맞춰 새로 그리므로 흐려지지 않습니다.

- **곡 제목 · 아티스트**: 칸보다 긴 제목은 좌우로 천천히 흐릅니다.
- **진행 바와 시간**: 현재 위치 / 전체 길이. 길이를 모르는 곡(라이브 등)은 `--:--`로 보여 줍니다.
- **⏮ ▶/⏸ ⏭ 버튼**: 재생 중인 앱(유튜브, 스포티파이 등)을 위젯에서 바로 조작합니다.
- **•••**: 우클릭 메뉴(소리 가져오기, 숨기기, 종료 등)를 엽니다.
- 정보는 Windows 미디어 세션(SMTC, 볼륨 키를 누르면 뜨는 미디어 팝업과 같은 정보)에서 읽습니다.
  크롬/엣지의 유튜브(영상 제목 · 채널 이름), 스포티파이 등에서 동작하고, 재생 중인 세션을 우선,
  없으면 Windows가 고른 현재 세션(일시정지 포함)을 보여 줍니다.
- 작은 헬퍼 `native/bin/win32-x64/wavepet-media.exe`가 처리하며, 소스는 `native/media/`(Rust)에 있습니다.

## 배경 설정

우클릭 또는 ••• 메뉴 → **설정 (배경 · 캐릭터)...**에서 카드 배경을 바꿀 수 있습니다. 바꾸는 즉시 반영되고 다음 실행에도 유지됩니다.

- **빠른 선택**: 그레이 글래스(기본), 네이비, 블랙, 퍼플, 핑크, 민트, 화이트
- **직접 고르기**: 색상 선택기로 아무 색
- **불투명도**: 20~100%
- 밝은 배경을 고르면 글자·버튼·파형이 자동으로 어두운 색으로 바뀝니다.

## 파형 동작

- 앱이 켜지면 자동으로 시스템 소리를 캡처해 파형 막대 40개로 보여 줍니다.
- 왼쪽이 저음, 오른쪽이 고음인 한 줄 배치입니다.
- 조용한 곡도 적당히 움직이도록 자동 게인이 들어가 있습니다.
- 출력 장치를 바꾸면(스피커 ↔ 이어폰/블루투스) 자동으로 다시 연결합니다. 그래도 멈춰 있으면
  우클릭 메뉴 → **오디오 다시 연결**을 누르세요.
- 30fps로 제한하고, 영상 캡처는 최소 해상도/1fps로 받아 CPU 사용을 줄였습니다.

## 소리 가져오기: Discord 소리 제외 (Windows 11)

우클릭 메뉴 → **소리 가져오기**에서 고를 수 있습니다(기본값: Discord 소리 제외).

| 방식 | 동작 |
|---|---|
| 전체 소리 | 스피커로 나가는 소리 전체 (Electron 루프백) |
| Discord 소리 제외 | Discord 음성/알림을 뺀 나머지 소리만. Discord가 꺼져 있으면 자동으로 전체 소리 |

- 제외 모드는 Windows 프로세스 루프백(Windows 10 빌드 20348 이상, 사실상 Windows 11)을 쓰는
  작은 헬퍼 `native/bin/win32-x64/wavepet-loopback.exe`가 처리합니다. 소스는
  `native/loopback/`(Rust, [wasapi](https://crates.io/crates/wasapi) 크레이트)에 있습니다.
- 헬퍼가 몇 번 연속으로 실패하면 이번 실행 동안은 자동으로 **전체 소리**로 돌아갑니다.
  현재 상태는 **소리 가져오기** 메뉴 맨 아래 "상태:" 줄에서 볼 수 있습니다.
- 헬퍼 다시 빌드하기(선택, Rust 필요):
  ```bash
  cd native/loopback
  cargo build --release
  # target/release/wavepet-loopback.exe 를 native/bin/win32-x64/ 로 복사
  ```

## 실행 방법

```bash
npm install
npm start          # 본 앱(위젯)
npm run audio-test # 오디오 캡처 확인용 테스트 창
```

## 1단계: 오디오 캡처 확인

`npm run audio-test`를 실행하면 테스트 창과 DevTools가 뜹니다. 브라우저에서 유튜브를
틀어 둔 뒤 **[캡처 시작]**을 누르고 아래 항목을 확인하세요.

| # | 해볼 것 | 정상이면 | 안 되면 |
|---|---|---|---|
| 1 | 캡처 시작 직후 | "오디오 트랙: 1개" | 0개면 루프백이 안 잡힌 것. DevTools Console 에러 확인 |
| 2 | 유튜브 재생 / 일시정지 | 재생 중 음량 숫자와 막대가 움직이고, 정지하면 거의 0 | 계속 0이면 다른 출력 장치를 캡처하는 중일 수 있음 |
| 3 | 소리와 막대를 같이 보기 | 체감 지연 없음 | 지연이 느껴지면 기록 |
| 4 | Windows 볼륨 낮추기 / 음소거 | 값이 어떻게 변하는지 기록 | 볼륨에 따라 크게 변하면 자동 게인(정규화)이 필요 |
| 5 | 스피커 ↔ 이어폰/블루투스 전환 | 전환 후에도 계속 잡힘 | 끊기면 장치 전환 시 재연결 로직이 필요 |
| 6 | 작업 관리자에서 CPU 확인 | 몇 % 이내 | 테스트 창은 화면 영상도 함께 캡처하므로 다소 높을 수 있음 |

## 폴더 구조

```
WavePet/
├─ main.js            # 창, 트레이, 우클릭 메뉴, 루프백 캡처 허용, 헬퍼 실행(오디오/곡 정보)
├─ preload.js         # 렌더러 ↔ main 통신
├─ src/
│   ├─ index.html
│   ├─ style.css
│   ├─ renderer.js    # 오디오 → 파형·캐릭터 루프, 드래그 이동
│   ├─ audio.js       # 소리 입력(전체 루프백 / 헬퍼 PCM), 장치 변경 시 자동 재연결
│   ├─ pcm-worklet.js # 헬퍼가 보낸 PCM을 분석 그래프로 흘려 보내는 AudioWorklet
│   ├─ spectrum.js    # 주파수 → 막대 높이 (로그 대역, 자동 게인, 대비, 보간)
│   ├─ visualizer.js  # 둥근 막대 파형 캔버스 렌더링
│   ├─ beat.js        # 소리 크기(loudness)와 박자(beat) 감지
│   ├─ player.js      # 플레이어 카드: 제목/아티스트, 진행 바, 재생 버튼
│   ├─ theme.js       # 배경 색/불투명도 적용, 밝은 배경이면 글자색 전환
│   ├─ settings.html  # 설정 창: 위젯 크기, 캐릭터 그림·크기, 애니메이션, 배경 (+ settings.js)
│   └─ pet.js         # 캐릭터 상태(idle/listening) 전환 기준, 그림 전환·크기, 고개 까딱·통통·음표 연출
├─ native/
│   ├─ loopback/      # Discord 제외 캡처 헬퍼 소스 (Rust)
│   ├─ media/         # 곡 정보 읽기 + 재생 조작 헬퍼 소스 (Rust)
│   └─ bin/win32-x64/ # 빌드된 헬퍼 exe
├─ assets/pet/        # 캐릭터 그림 idle / left / right
└─ audio-test/        # 1단계 오디오 캡처 확인용 (확인 후 삭제 예정)
```

4. 편의 기능: 휠 크기 조절, 캐릭터 이미지 교체, 파형 색/막대 수/배경 패널 설정 저장
