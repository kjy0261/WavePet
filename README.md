# WavePet

작업할 때 켜 두는 데스크탑 위젯입니다. 유튜브 등에서 음악을 틀면 왼쪽 파형이 소리에 맞춰
움직이고, 오른쪽 캐릭터가 음악을 같이 듣는 것처럼 반응합니다. Electron 기반이며,
**시스템 오디오 루프백 캡처**로 스피커로 나가는 소리를 그대로 분석하므로 브라우저,
스포티파이 등 어떤 앱에서 재생하든 동작합니다(Windows 기준).

> 현재 **2단계(파형이 소리에 반응)** 상태입니다. 캐릭터 반응은 아직 없습니다.

## 파형 동작

- 앱이 켜지면 자동으로 시스템 소리를 캡처해 파형 막대 40개로 보여 줍니다.
- 저음이 가운데, 고음이 양옆에 오도록 배치해 가운데가 불룩한 모양이 됩니다.
- 조용한 곡도 적당히 움직이도록 자동 게인이 들어가 있습니다.
- 출력 장치를 바꾸면(스피커 ↔ 이어폰/블루투스) 자동으로 다시 연결합니다. 그래도 멈춰 있으면
  우클릭 메뉴 → **오디오 다시 연결**을 누르세요.
- 30fps로 제한하고, 영상 캡처는 최소 해상도/1fps로 받아 CPU 사용을 줄였습니다.

## 실행 방법

```bash
npm install
npm start          # 본 앱(위젯)
npm run audio-test # 오디오 캡처 확인용 테스트 창
```

## 1단계: 오디오 캡처 확인

`npm run audio-test`를 실행하면 테스트 창과 DevTools가 뜹니다. 브라우저에서 유튜브를
틀어 둔 뒤 **[캡처 시작]**을 누르고 아래 항목을 확인하세요.

| # | 해볼 것 | 정상이면 | 안 되면 |
|---|---|---|---|
| 1 | 캡처 시작 직후 | "오디오 트랙: 1개" | 0개면 루프백이 안 잡힌 것. DevTools Console 에러 확인 |
| 2 | 유튜브 재생 / 일시정지 | 재생 중 음량 숫자와 막대가 움직이고, 정지하면 거의 0 | 계속 0이면 다른 출력 장치를 캡처하는 중일 수 있음 |
| 3 | 소리와 막대를 같이 보기 | 체감 지연 없음 | 지연이 느껴지면 기록 |
| 4 | Windows 볼륨 낮추기 / 음소거 | 값이 어떻게 변하는지 기록 | 볼륨에 따라 크게 변하면 자동 게인(정규화)이 필요 |
| 5 | 스피커 ↔ 이어폰/블루투스 전환 | 전환 후에도 계속 잡힘 | 끊기면 장치 전환 시 재연결 로직이 필요 |
| 6 | 작업 관리자에서 CPU 확인 | 몇 % 이내 | 테스트 창은 화면 영상도 함께 캡처하므로 다소 높을 수 있음 |

## 폴더 구조

```
WavePet/
├─ main.js            # 창, 트레이, 우클릭 메뉴, 루프백 캡처 허용
├─ preload.js         # 렌더러 ↔ main 통신
├─ src/
│   ├─ index.html
│   ├─ style.css
│   ├─ renderer.js    # 오디오 → 파형 루프, 드래그 이동, (예정) 캐릭터 상태 관리
│   ├─ audio.js       # 루프백 캡처, 장치 변경 시 자동 재연결
│   ├─ spectrum.js    # 주파수 → 막대 높이 (로그 대역, 가운데 배치, 자동 게인, 보간)
│   └─ visualizer.js  # 대칭 둥근 막대 파형 캔버스 렌더링
├─ assets/pet/        # 캐릭터 이미지 (idle.png는 자리표시용 샘플)
└─ audio-test/        # 1단계 오디오 캡처 확인용 (확인 후 삭제 예정)
```

## 로드맵

1. 뼈대 + 오디오 캡처 확인 ✅
2. **파형: 루프백 캡처를 본 앱에 연결하고, 로그 스케일 + 가운데 배치 + attack/release 보간 적용** ← 현재
3. 캐릭터: 소리가 나면 `listening`, 박자(저음 에너지 급증)마다 까딱이는 `beat` 상태
4. 편의 기능: 휠 크기 조절, 캐릭터 이미지 교체, 파형 색/막대 수/배경 패널 설정 저장
5. Windows 설치 파일 빌드
